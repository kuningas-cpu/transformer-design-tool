## 1. 核心模型（全部按伏秒平衡，不使用 4.44 正弦系数）

统一关系：**ΔB = V·t/(Np·Ae)**，其中 V·t = 施加电压 × 导通时间。

| 拓扑 | 输出电压方程（n = Np/Ns） | 磁通（一个周期） | D 的定义 | 极性 |
|---|---|---|---|---|
| 反激 / ACF | Vo = Vin·D/((1-D)·n) | ΔB_pp = Lp·ΔI/(Np·Ae) = Vin·D/(Np·Ae·Fs) | 开关导通占空比（≤0.6） | 单极性 Bpk=ΔB |
| 正激 | Vo = Vin·D/n | ΔB_pp = Vin·D/(Np·Ae·Fs) | 单管导通占空比（1:1 复位绕组 ≤0.5） | 单极性 Bpk=ΔB |
| 推挽 | Vo = 2·Vin·D/n | ΔB_pp = 2·Vin·D/(Np·Ae·Fs) | 每个开关占空比（<0.5） | 双极性 Bpk=ΔB_pp/2 |
| 半桥 | Vo = Vin·D/n | ΔB_pp = (Vin/2)·D/(Np·Ae·Fs) | 每个开关占空比（<0.5） | 双极性 Bpk=ΔB_pp/2 |
| 全桥 | Vo = 2·Vin·D/n | ΔB_pp = Vin·D/(Np·Ae·Fs) | 每个桥臂占空比（<0.5） | 双极性 Bpk=ΔB_pp/2 |
| LLC | Vo = Vin_nom/(2n)（谐振点） | ΔB_pp = (Vin/2)·0.5/(Np·Ae·Fs) | 固定 0.5 | 双极性 Bpk=ΔB_pp/2 |

与 `transformer_design_common_topology_zh_en.md` 里 `B = V·D/(Np·Ae·fs)`、`Np = Vin(min)·Dmax/(Bmax·Ae·fs)`、
半桥 `Vout ≈ D·Vin·Ns/Np` 一致。

**匝数**：`Np = max(磁通下限, 饱和下限)`，再取 `Ns` 为"使 Vin_min 处所需占空比最接近 D_max 且不超上限"的整数，
然后**用整数匝数反算工作点**并报告所需占空比（而不是把变比按理论值硬套）。

**电流**：
- 反激 CCM：`I_avg(on) = Pin/(Vin·D)`，`Ipk = I_avg(on)/(1-K/2)`，`ΔI = K·Ipk`，`Lp = Vin_min·D_max/(ΔI·Fs)`；K=2 即 BCM。
- 正激/桥式：原边脉冲 = 反射输出电流 `(Iout±ΔI_L/2)/n` + 励磁分量 `ΔI_m = V·t/Lm`（Lm = AL·Np²）。
- 推挽：半绕组电流 = 2·(Iout+ΔI_L/2)/n，一个周期只导通一次；窗口与铜损按"半绕组 ×2"累计。
- RMS 用梯形精确公式，已与数值积分逐点对比。

**损耗与热**：`R_dc = ρ(T)·MLT·N/(A_cu)`，`P_cu = Σ I_rms²·R·F_R`（含高频系数），
`P_core = Pcv_ref·(Fs/100kHz)^α·(B_ac/100mT)^β·Ve`（B_ac = ΔB_pp/2，正弦拟合约定），
`ΔT = (P_core+P_cu)·Rth`，ρ 按绕组实际温度迭代收敛；并给出满足目标温升所需的最大 Rth。

**窗口**：一次 + 二次（+ 正激复位绕组、桥式/推挽按绕组数）共享同一窗口，
`fill = Σ裸铜面积·k_pack/Aw`，与 `Ku` 上限比较，并给出满足 Ku 所需的 Aw。

**反激气隙**：`AL_req = Lp/Np²`，`l_g = μ0·Ae/AL_req − le/µi`；
若用户直接给定 AL，则改为**扫描匝数**（因为 AL 固定时 Bpk 对 Np 非单调：Lp∝N²，Bpk 先降后升），
取同时满足 `Bpk ≤ Bsat·降额` 与 `ΔB_pp ≤ ΔB_target` 的最小匝数；无解时明确报"AL 偏大/磁芯偏小"。

## 2. 校核清单（判定不再依赖用户自报数值）

磁通峰值 vs Bsat·降额（软磁铁氧体按 100°C 数据）、Vin_min 所需占空比 vs 拓扑上限、
窗口填充率 vs Ku、原/副边电流密度 vs J 目标、温升 vs 目标、股线直径 vs 趋肤深度（1.5δ 警告、3δ 不通过）、
所需气隙、复位绕组匝比、Vin_max 处占空比下限、工作模式（CCM/DCM）、LLC 谐振点输出偏差。
再加上**内部一致性自检**（功率波形平衡、能量守恒、磁通两条路径、安匝平衡、AL/Lm/填充率/占空比往返），全部以相对误差显示，方便现场复核。

## 3. 相对 v1 修掉的主要问题

1. 首次加载不渲染（v1 的 `safeRender` 要求不存在的 `coreName`，页面停在占位 0）。
2. 匝数用正弦 4.44 公式导致偏小 4.44 倍（默认工况 8.4 匝被算成 2 匝，实际磁通 20 T 级）。
3. "B check" 是恒等式（永远等于用户输入的 ΔB），不是校核。
4. 半桥用推挽/全桥的 2×Vin 公式（与本目录公式文档矛盾，匝数少一半）。
5. 次级电感公式反向（`Lp/n²` 写成 `Lp·n²` 的错误方向已修正为 `Ls = Lp/n²`）。
6. 副边峰值电流报的是放电期平均值（偏小约 2 倍），且与自身 Ipk 不自洽。
7. Lp 按 CCM、Ipk 按 DCM 混用（自相矛盾），现在统一为"先定 K，再由此得 Lp、Ipk、ΔI"。
8. 窗口钳位静默破坏变比（v1 会出现 Vout 100 V 设计实际得 11 V 但仍显示"可用"）。
9. 一/二次各自独占整个窗口、匝数下限硬编码 3 匝；现在共享窗口并按拓扑计算。
10. 温升与铜损无关（铜损是 0.12·Pin 常数）；现在按线径/股数/并联真实算铜损并迭代温度。
11. 磁芯损耗用 `max(Ae*2.5,200)` 当体积并乘无依据系数；现在用 Ve = Ae·le 与可编辑的 Pcv/α/β。
12. 输入框形同虚设（Vin_max、J、频段/功率段/尺寸段、线径对温升无影响等）→ 现在除拓扑无关项外全部参与计算，并有回归测试。
13. `PQ35/PQ26` 键名不匹配导致功率上限查表落默认值；v2 不再用硬编码功率表，改为逐磁芯实算对比。
14. 自动选线只取整到 AWG 会把铜面积放大 20~50% 导致填充率虚高：现在在 0.05 mm 栅格上同时选线径与股数。
15. K=2（BCM）时除零产生 NaN 匝数；已改为 BCM 分支并加兜底。
16. 正激复位绕组匝比方向错误（`(1-D)/D` 应为 `Nr/Np ≥ D/(1-D)`，等价 `D_max = Nr/(Nr+Np)`）。

## 4. 使用注意与范围

- **磁芯/材质预设是典型值**（Ae/le/Aw/MLT/µi/Bsat/Pcv/α/β），正式设计请用数据手册数值覆盖输入框；
  Aw 与 MLT 不确定性最大，工具会给出"满足 Ku 所需 Aw"，便于与骨架实际窗口比对。
- 预设只覆盖 MnZn 铁氧体（EE/EFD/ETD/PQ/RM/EP/EPC）。粉末磁环（Kool Mu/High Flux）与低频 EI 的
  饱和/损耗模型不同，请用"Custom"自行填参。
- LLC 只做变比/匝数/磁通/窗口/损耗估算，谐振腔（Lr、Cr、Lm、Q、增益曲线、软开关范围）需另做设计。
- 整流二极管正向压降用 Vf 输入；副边整流方式（中心抽头/全桥）只影响窗口与绕组 RMS 统计。
- 未建模：漏感与绕组排布、邻近效应细节（用 F_R 折算）、绝缘/安规距离、EMI、启动/短路等瞬态。
- 结论只是"快速设计/校核"，最终以样机实测为准。

## 7. 输入面板的动态显示（data-show 规则）

### 7.1 为什么

七种拓扑 + 三种输入方式（直流 / 交流 + 整流母线 / 交流 + PFC）叠在一起时，面板上有三分之一以上的输入项
与当前工况无关：选直流时整片交流前端参数（Vac、工频、C_bus、ESR、源阻、桥压降、保持时间、PFC 母线）没有用；
选交流时 Vin_min / Vin_max 会被母线数值仿真覆盖，显示出来反而让人以为要手填；反激没有输出电感、LLC 没有原边纹波比 K。
隐藏这些项能让"填哪些、不填哪些"一眼看清，也避免把无关数值当成有效输入。

### 7.2 怎么做的

1. 每个条件相关的 `<div class="field">` 或小节标题上写一条 `data-show` 属性；
2. `render()` 的第一件事就是 `updateVisibility()`：`document.querySelectorAll('[data-show]')`，
   逐项按规则判定，命中则 `style.display = ''`，否则 `'none'`；
3. 输入项变化本来就会触发 `render()`（每个输入都挂了 `input`/`change` → `render`），所以切换即刷新；
4. **隐藏不等于清空**：被隐藏的输入保留原值，切回该工况数值照旧；引擎也只在该工况真正用到它们时才读取。

规则语法（`showRuleHit`，见 UI 脚本）：

```
data-show = 分支 ('|' 分支)*        竖线 = 或
分支      = 条件 ('&' 条件)*        &   = 且
条件      = 键 ':' 候选值 (',' 候选值)*   命中任一候选值即成立
键        = ac        取 #acMode     (dc / ac / pfc)
            topo      取 #topology
            rect      取 #rectDevice (diode / sr1 / sr2)
            resetMode 取 #resetMode  (cap / winding)
```

### 7.3 全部规则（与工具里的属性一一对应）

| 键 | 取值 | 规则 | 说明 |
|---|---|---|---|
| `vinMin` `vinMax` | `ac:dc` | 直流输入才显示 | 交流模式下母线仿真会覆盖这两项，结果区显示实际取值 |
| `vacMin` `vacMax` `fline` `cbusUf` `cbusEsr` `rsAc` `vdBridge` | `ac:ac` | 只有"交流 + 整流母线"用 | 母线数值仿真的输入（PFC 模式不用） |
| `holdMs` `holdVmin` | `ac:ac` | 同上 | 保持时间校核只在整流母线模式计算 |
| `pfcBus` | `ac:pfc` | 只有 PFC 模式用 | 恒定母线电压 |
| `rippleK` | `topo:Flyback,Active Clamp Flyback` | 反激类 | 原边纹波比 K = ΔI/Ipk |
| `rippleLout` `nlDia` `nlStrands` `nlPar` `nlGiven` `lmGiven` `naux` | `topo:Forward,Push-Pull,Half-Bridge,Full-Bridge` | Buck 型副边 | 输出电感只存在于正激/推挽/半桥/全桥；辅助绕组与输出电感同磁芯 |

## 8. 面板顺序与「续流管」口径（2026-10-15）

### 8.1 面板顺序

设计输入卡片按"先输入、后输出、再构造"排：

```
输入类型与输入电压（输入类型 / Vin_min、Vin_max 或 Vac…）
  → 规格（拓扑、Fs、Vout、Iout、Vf、η、Vin_nom、次级整流、次级整流器件）
  → 拓扑工作点 → 磁芯 → 材质 → 绕组 → 输出级 → LLC 谐振腔
  → 校核模式 → 窗口与绝缘 → 热
```

Vin_min / Vin_max 与交流前端参数同属"输入"，放同一块里由 `data-show` 按输入类型切换；拓扑与频率随后。

### 8.2 只有 Buck 型副边才有续流管

| 拓扑族 | 副边结构 | 续流管 | 引擎里的 `rectDevice` 处理 |
|---|---|---|---|
| 反激 / ACF | 单只整流管，关断期导通给输出电容充电 | **无** | `sr2` 归一为 `sr1`（单管）并给出提示 |
| 正激 / 推挽 / 半桥 / 全桥 | Buck 型副边（带输出电感）：整流管导通期、续流管关断期 | 有 | `diode` / `sr1` / `sr2` 三档都保留 |

### 8.3 损耗口径

| 情形 | 引擎公式 | 说明 |
|---|---|---|
| 有续流管（Buck 型副边） | `P_diode = Vf·Iout` | 整流管 `D·Iout` + 续流管 `(1-D)·Iout`，一个周期内合计恰为 `Iout` |

## 10. 开关管电压应力 Vds,pk 与 0.85 降额的来历（2026-10-15）

校核清单里"开关管电压应力 Vds,pk ≤ 0.85×耐压"这一行，完整链条是：

```
Vds,pk = Vin_max + V_res,pk + ΔV_Lk

V_res,pk = I_m,pk·√(Lm/C_res) = n·Vo / (Fs·√(Lm·C_res))      复位电容被励磁电流充到的峰值
          当 C_res 取到上限 (1-D)²/(π²·Lm·Fs²) 时 → π·n·Vo/(1-D)（与 Lm、Fs 无关的闭式）

ΔV_Lk   = I_pk,pri·√(Lk/C_res)                                漏感能量 ½·Lk·I² 全部灌进 C_res（上界）

校核限值 = 0.85 × Vds_rated
```

- **为什么是 Vin_max 那一项**：关断瞬间开关管两端是输入母线电压加复位电容电压，所以输入最高、复位峰值最高时最恶劣。
- **C_res 与应力是反比**：`V_res,pk` 与 `ΔV_Lk` 都 ∝ 1/√C_res，电容越小应力越高、复位越快；C 超过上限则复位在下一个周期前完不成（饱和）。
  工具"自动取上限"= 复位在关断期的前 1/2 内完成（留 2 倍时间余量），此时两项都最小。
- **0.85 不是器件参数，是降额约定**（工具固定用它，另在 0.9×限值 处给"接近上限"提示）：① BVdss 标称 25°C，高温下雪崩击穿电压下降；
  ② Vin_max 本身有 +5~10% 公差；③ ΔV_Lk 只是解析上界，实测还叠加漏感振铃与尖峰；④ 电感、驱动与器件有批量一致性偏差。业界常用 80%~90%，高温/高压取 0.8。
- **漏感是关键输入**：填 0 时工具会明确提示"Vds,pk 被低估"。本板（36 V、AL=1146 nH/N²、12 匝 → Lm=165 µH、C_res 自动 2.9 nF）：
  V_res,pk ≈ 73.5 V；Lk=0.8 µH → ΔV_Lk ≈ 135 V → Vds,pk ≈ 245 V（超 250 V 档的 212.5 V 限值）；Lk=0.2 µH → ΔV ≈ 68 V → Vds,pk ≈ 177 V 通过。

工具里现在有三处能看到它：**设计步骤**里有独立一行"开关管电压应力 Vds,pk（电容谐振复位）"（给出公式 + 代入数值 + 通过/不通过与怎么改）、
**输出级卡片**里有一段"正激磁复位（电容谐振复位）"提示（含限值）、**页尾速查表**新增"开关管耐压降额 0.85"一行解释来历。

## 11. 热阻 Rth (K/W) 是谁的（2026-10-15）

**是这颗变压器自己的热阻**：从绕组/磁芯热点到环境，用来校核绕组温升。工具里的用法：

```
ΔT      = (P_core + P_cu)·Rth        变压器自身的两种损耗合成一个热源（集中热阻模型）
T_热点  = T_环境 + ΔT                 这个温度同时用来算 ρ(T) 与趋肤深度 → 又回头影响铜损
Rth_max = ΔT_目标 / P_总              反过来告诉你"要满足温升目标，热阻最多能是多少"
```

因为温升与铜损互相耦合，`ΔT` 对 `Rth` 是**超线性**的：Rth 翻倍时 ΔT 会超过 2 倍（验证：本板 28 → 56 K/W，ΔT 从 58.6 K 涨到 148.2 K，2.53 倍）。

- **不是数据手册参数**：同一颗磁芯，坐在大铜箔上/点胶灌封/有风 与 悬空无风能差 2~3 倍。取值优先级：① 实测反推 `Rth = (T_热点 − T_环境)/P_损耗`；② 估算 `Rth ≈ 1/(h·A_表面)`，自然对流+辐射等效 h ≈ 10~15 W/(m²·K)（EPC19 级表面 ≈2×10⁻³ m² → 约 30 K/W）；③ 经验值：EPC19/EP20 级自由空气 25~35，EE16/EP13 级 40~60，点胶灌封或贴大铜箔 15~25，密闭无风小腔 >40。
- **输出电感（2 号）借用同一个 Rth**：它自己的损耗与温升独立计算（`ΔT_L = P_电感·Rth`，且其 ρ 用 `T_环境+40` 固定值，所以 ΔT_L 严格线性于 Rth），但**不计入变压器温升**。两块都是 EPC19 骨架、装法相同时这个借用是合理近似。
- 页面三处可查：热/热力学小节下方新增 **"Rth 是谁的？"** 提示块（含实测反推与估算法）、设计步骤里的温升行标题改为"温升（Rth = 变压器自身'热点→环境'热阻）"、页尾速查表新增 **"热阻 Rth (K/W)"** 一行。

## 12. 复位电容的可行窗口：这个耐压档到底能不能用（2026-10-15）

开关管耐压不是"高于 Vds,pk 就行"，而是要同时满足两个反向的要求——**耐压要求 C_res 越大越好（压低复位峰值），复位时间要求 C_res 越小越好**：

```
Vds,pk(C) = Vin_max + (A + B)/√C        A = I_m,pk·√Lm（励磁项）, B = I_pk,pri·√Lk（漏感项），两项都 ∝ 1/√C
  ⇒ C ≥ C_min = [ (A + B) / (0.85·Vds_rated − Vin_max) ]²        耐压下限（要求 0.85·Vds_rated > Vin_max）
复位必须在最小关断期内完成（关断期最小 = Vin_min 处 D 最大）：
  t_reset = (π/2)·√(Lm·C) ≤ (1 − D(Vin_min)) / Fs
  ⇒ C ≤ C_max = [ 2(1 − D) / (π·Fs) ]² / Lm                      复位时间上限（工具"自动取上限"= 该值的 1/4，留 2 倍时间余量）
窗口为空（C_min > C_max）⇒ 该耐压档在这组 Vin_max / 漏感 下不可行
```

工具现在会：给出 `C_min`、`C_max`、窗口是否为空、**最小可行的标准耐压档**（100/150/200/…/1000 V）以及在同样电容下**允许的最大漏感** `Lk_max`；
新增两条校核行（`C_res ≤ 关断期内复位上限`、`C_res ≥ 耐压要求下限`）与告警；输出级卡片同步显示窗口结论。

以本板为例（正激 + 电容复位、Lm = 165 µH、Fs = 200 kHz、Vin 18~36 V、D(Vin_min) = 0.565 → C_max = 11.6 nF）：

| Vin_max | Lk | 需要 C_res ≥ | 允许 C_res ≤ | 结论 |
|---|---|---|---|---|
| 36 V | 0.8 µH | 52.6 nF | 11.6 nF | **窗口为空：100 V 档不可行，最小可行档 = 200 V** |
| 36 V | 0.2 µH | 24.1 nF | 11.6 nF | 窗口为空 → 最小可行档 = 150 V |
| 36 V | ≈ 0 | 6.5 nF | 11.6 nF | 可行，但 C_res 只能落在 6.5~11.6 nF 的窄带里 |

几点工程判断：① `ΔV_Lk` 是"漏感能量全部灌进 C_res"的**上界**（实际有绕组阻尼、二极管换流、RC 吸收或 MOS 雪崩吸收，实测尖峰会低一些），所以窗口为空 ≠ 一定烧管，但说明**余量不够、必须实测复核**；
② 100 V 器件在 36 V 输入 + 电容复位下本来就很紧：扣掉 Vin_max 与 0.85 降额只剩 49 V，而励磁项单独就要 37 V（C 取到复位上限时）；
③ 判断顺序应为：先量 **C_res 实际值**与**实测漏感 Lk**，再看窗口；若窗口为空，要么提高耐压档，要么减小漏感（夹层/三明治绕法），要么降低 Vin_max。

### 12.1 板上实测 C_res = 1 nF（100 V 管 IRF540N，Vin_max = 36 V）的结论

把 1 nF 填进工具（Lm = 165 µH、Fs = 200 kHz、Lk = 0.2 µH 作示例）：

| 量 | 值 | 说明 |
|---|---|---|
| `V_res,pk`（励磁项） | **125.2 V** | 1 nF 时励磁项单独就超过 100 V 管子；漏感项另计 |
| `ΔV_Lk` | 81 V（Lk=0.1）/ 115 V（0.2）/ 230 V（0.8） | `∝ 1/√C`，与 Fs 无关 |
| `Vds,pk` | 161 V（Lk=0）~ 391 V（Lk=0.8） | 限值 85 V（100 V × 0.85） |
| 复位时间 | 0.64 µs（关断期 2.18 µs） | 1 nF 的复位**来得及**，问题只在电压 |
| 耐压窗口 | 需要 C ≥ 24.1 nF，但复位时间只允许 C ≤ 11.6 nF | **100 V 档无解** → 最小可行档 = 150 V |

结论与建议（按优先级）：

1. **把 C_res 从 1 nF 加大到 8.2~10 nF**（Lk=0.2 µH 时）：`V_res,pk` 125→44 V、`ΔV_Lk` 115→40 V，150 V 档立刻可行，且复位仍在关断期内完成（1.83 µs < 2.18 µs）。
2. **开关管换 150 V 档**（低 Rds 型号顺便解决 IRF540N 导通损耗大的问题：44 mΩ/25 °C 在 5.7 A 有效值下约 1.4 W，热态 2 W 以上）。
3. **漏感要实测**：`ΔV_Lk` 是"漏感能量全部灌进 C_res、无阻尼"的上界；实际有绕组阻尼/二极管换流/RC 吸收。1 nF 下即使 Lk 只有 0.1 µH，尖峰仍有 81 V。
4. 若维持 1 nF 且不换管：MOS 会靠**雪崩钳位**把尖峰压在 ~100 V（每周期把几十 µJ 的能量烧在器件里，200 kHz 下约 1 W 级），能工作但没有余量、损耗与可靠性都要打折。
5. 若你板上这 1 nF 其实是**串了电阻/二极管的吸收电容**（不是直接并联在初级两端的复位电容），把拓扑讲清楚，判定会完全不同——请确认接法。

### 12.2 实测 Vds,pk = 60 V 与解析上界的对账（2026-10-15）

用户实测：Vin_max = 36 V 时开关管 Vds 峰值只有 **60 V**（工具解析上界 161~391 V，差 2.7~6.5 倍）。

把实测值填进新增的"实测 Vds,pk"输入后，工具会反推：

| 量 | 值 | 含义 |
|---|---|---|
| 实测复位峰值 | 60 − 36 = **24 V** | 电容上真正出现的峰值 |
| 等效复位电容 | **27.2 nF**（现值 1 nF） | 若峰值只由励磁项决定，需要这么大的电容 |
| 等效 Lm | **4.49 mH**（现值 165 µH） | 或：励磁电流比我算的小 5.2 倍 |
| 等效 Fs | **1044 kHz**（现值 200 kHz） | 或：开关频率比填写值高 5.2 倍 |
| 进入电容的能量 / 励磁能量 | **3.7%** | 96% 的励磁能量没进这个电容 |
| `Vin_max + n·Vo` | **46.2 V** | 若磁化能量经副边回馈到输出，drain 会被钳在这个电压 + 漏感尖峰 ≈ 60 V ✅ |

**结论**：60 V 这个数**不可能**由"1 nF 电容吸收全部励磁能量"解释（那需要 4.5 mH 或 1 MHz）。
最自洽的解释是**磁化能量没有走这个电容**：关断期副边整流管反向导通，能量回馈到输出，drain 被钳在 `Vin_max + n·Vo ≈ 46 V` 加一点漏感尖峰 —— 正好 60 V。
也就是说这 1 nF 更像**吸收/缓冲电容**，复位靠副边通路（或还有别的钳位元件）。

工具的行为也随之调整：填了实测值后，**判决以实测为准**（实测行进入核心校核，解析那行与由它推出的"C_res 下限"降级为外围项，仍列出但不参与判决），
并在提示里说明"模型判定与实测矛盾，不代表你板子会超压"。

待确认（决定这个结论是否成立）：① **Fs**（实测 drain 波形周期）；② 副边整流结构（全桥 4 只 / 中心抽头 2 只 / 单管 + 续流）；③ 这 1 nF 的确切接法（是否串了电阻或二极管）；
④ 探头带宽与地线（漏感尖峰只有几十 ns 宽，普通探头/长地线会漏掉）。

### 12.3 用户确认参数后的最终对账（Fs = 250 kHz、副边 1 整流 + 1 续流、1 nF 并在初级两端、波形是"慢慢升到峰值再落回"）

**关键判据（本轮加入工具）**：无损谐振复位存在一个与 Lm、C、Fs 无关的**理论下限**

```
V_res,pk ≥ π·n·Vo / (1−D)        （只要复位能在本周期内完成；由"复位半周期 ≤ 关断期"与 V ∝ 1/√(Lm·C) 联立消掉 Lm、C 得到）
```

本板（n = 12/23 = 0.5217、Vo = 19.5 V、Vin_max = 36 V → D = 0.283，Vin_min = 18 V → D = 0.565）：

| 量 | 值 |
|---|---|
| Vin_max 处的理论下限 | π·0.5217·19.5/0.717 = **44.6 V** |
| 解析上界（1 nF、Lm = 165 µH、Fs = 250 kHz，含漏感项） | 100 V（励磁项）～ 251 V |
| **实测复位峰值** | 60 − 36 = **24 V** ← **低于理论下限 44.6 V** |

**24 V < 44.6 V ⇒ "1 nF 纯电容谐振复位"在数学上不成立**（无论 Lm、C、Fs 取什么值都做不到这么小的峰）。
所以复位回路里一定还有别的东西，工具给出两条量化候选：

| 候选 | 量化 | 代价 |
|---|---|---|
| ① 电容上串阻尼电阻（R-C 吸收/耗散复位） | 重阻尼近似 R ≈ I_m,pk·Lm/(V_res·C) ≈ **1.7 kΩ** | 每周期磁化能量 ½·Lm·I_m,pk² ≈ 5 µJ 基本都耗在电阻上 ≈ **1.25 W** |
| ② 初级两端另有钳位器件（TVS/RCD） | drain 被钳在实测的 60 V | 钳位器件承担尖峰能量 |

另两个反证：把 1 nF 换成"能只升到 24 V"的 17.4 nF → 复位半周期变成 5.33 µs，而最小关断期只有 1.74 µs，复位来不及（磁芯会逐步偏磁）；把 Fs 或 Lm 改到能凑出 24 V 需要 1044 kHz 或 2.9 mH，都与 UC3843 + EPC19/PC44 的常识冲突。

**下一步请核对**：① 这只 1 nF 是否**串了电阻**（典型 1 kΩ 级；也可能是 RCD 里的电阻）；② 初级两端是否还有 **TVS/钳位**；③ 波形**上升时间**：模型给 (π/2)·√(Lm·C) = 0.64 µs，若实际明显更快 → 有阻尼；若明显更慢 → Lm·C 比模型大（但那样幅值会更高，与 60 V 矛盾）。

### 12.4 示波器波形（Tektronix DPO 2014B，2 µs/div、20 V/div）带来的修正

用户提供的波形：一路是栅极方波（占空比 ≈ 0.25~0.3），另一路是 drain 上的**光滑圆拱**——先升到峰再落回开通电平，拱形占满关断期，
**没有平台（不是钳位）**、**没有台阶/过冲（不像串了电阻）**。这与用户说明的"没有串电阻、没有钳位、电容并在初级两端"一致。

**这一版把理论下限算完整了**（之前只算了励磁幅度那一项，漏掉了"电容在导通期已经被充到 Vin"这一项）：

```
导通期：开关把 drain 拉到 ~0，绕组另一端是 Vin ⇒ 复位电容此刻已经充到 Vin
关断期：母线还要再往电容里灌 Vin·Q 的电荷（能量方程 ½C·v² = ½Lm·I² + Vin·C·v）
⇒ Vds,pk = Vin + √(Vin² + (I_m,pk·Z)²) ≥ 2·Vin            （即使励磁电流为零）
再加上"复位必须在本周期内完成"给的 I_m,pk·Z ≥ π·n·Vo/(1−D)
⇒ Vds,pk ≥ Vin_max + √(Vin_max² + (π·n·Vo/(1−D))²)         （与 Lm、C_res、Fs、甚至 Vin 都基本无关）
```

| Vin_max | 最小励磁幅度 π·n·Vo/(1−D) | 完整下限 |
|---|---|---|
| 18 V | 73.5 V | **93.7 V** |
| 24 V | 55.5 V | **84.5 V** |
| 30 V | 48.4 V | **86.9 V** |
| 36 V | 44.6 V | **93.3 V** |

**实测 60 V 低于整条下限**（也低于最简单的 2·Vin = 72 V），所以工具现在会反问：**"这组波形是在多大输入电压下测的？"**
——纯电容复位时 Vds,pk ≥ 2·Vin ⇒ 60 V 的峰值最多对应 **Vin ≤ 30 V**（把励磁项算进去约 24~27 V）。
如果确实是在 Vin_max = 36 V 测到的 60 V，那说明"单管串联在初级 + 初级并联电容"这个模型与实板不一致（例如双管正激那类把磁化能量回馈到母线的结构，drain 只被钳在 Vin 附近），需要按实际电路改模型。

### 12.5 用户确认（Vin = 24 V 下测得 60 V、6-7/5-8 是 12 匝并联）之后的定案

把"环形解"（Lm-C 在关断期自由振荡，稳态由**电流周期性**决定，而不是"电流衰减到零"的简单解）加进工具后，本板出现了决定性结果：

```
简单解（I_off = ΔI）：  Vds,pk = Vin + √(Vin² + (ΔI·Z)²)，ΔI = n·Vo·T/Lm
环形解（无阻尼稳态）：  I_off·(1 − cosΩ) = ΔI + (Vin/Z)·sinΩ，Ω = t_off/√(Lm·C_res)
                        Vds,pk = Vin + √(Vin² + (I_off·Z)²)
```

用承认书的 165 µH（AL = 1146 @ 12 匝）、C_res = 1 nF、Fs = 250 kHz、Vin_max = 36 V 计算：

| 估计 | 结果 |
|---|---|
| 简单解 | 251 V |
| **环形解** | **471 V，Ω = 405°，I_off = 1.07 A**（对应 B ≈ 0.29 T，几乎饱和） |

也就是说：**若初级真是 165 µH，这个复位谐振会把电压和电流都推爆**（无阻尼 Q ≈ Z/R ≈ 406/0.02 ≈ 2×10⁴，绕组与磁芯损耗压不住），转换器不可能像现在这样稳定工作。

而**用实测的 60 V 反推**（环形解）得到：**Lm ≈ 548 µH，即 AL ≈ 3804 nH/N²（12 匝）**——与"不开气隙"的 EPC19/PC44 理想值（µ0·µi·Ae/le ≈ 3700~4900 nH/N²）吻合，也与"磁芯不开气隙"吻合。

**结论**：承认书上的"电感量 165 µH"很可能**不是 12 匝初级绕组本身的电感**，而更像**其中一段 6 匝绕组**的电感：
`165 µH = AL·6²` ⇒ AL ≈ 4583 nH/N²（正是无气隙理想值），**两段串联成 12 匝后初级 ≈ 660 µH**。
这与 DCR 也自洽：每段 6 匝 0.4 mm×2 约 15.6 mΩ，两段串联 ≈ 31 mΩ ≈ 承认书的 32 mΩ。

**请用 LCR 表实测四种接法**（唯一能定案的测量）：6-7 单独、5-8 单独、两段串联、两段并联。

- 若 6-7/5-8 各自 ≈ **165 µH** → 每段是 6 匝（AL ≈ 4600 = 不开气隙），初级必须**串联**才是 12 匝 → 初级 ≈ 660 µH；工具里把"承认书电感量"改成测量值并把匝数填 6，或直接把 AL 填 ≈ 4600。
- 若各自 ≈ **660 µH** → 每段就是 12 匝（AL ≈ 4600），则承认书那个 165 µH 需要供应商解释来源（测的条件/绕组）。

### 12.6 用户确认绕组后：**是复位电容 1 nF 不对，而且我上一版的下限算错了 2 倍**（2026-10-15）

用户确认：承认书写的是 `0.4×2×12`——**一个绕组 12 匝、0.4 mm 线 2 股**，两段这样的绕组在 PCB 上并联 ⇒ 初级 = 12 匝、承认书 L = 165 µH ⇒ AL = 1146 nH/N²（工具原假设成立）。

**同时必须纠正我上一版的理论下限**：我漏了环形解在 Ω = π 时电流会反号这一半，把"最小励磁幅度"写成了 `π·n·Vo/(1−D)`，正确的是 `π·n·Vo/(2(1−D))`（因为 Ω = π 时 `I_off = ΔI/2`）。于是正确的下限是

```
Vds,pk ≥ Vin + √( Vin² + ( π·n·Vo / (2(1−D)) )² )
```

本板 @Vin = 24 V（D = 0.424）：励磁幅度下限 = π·10.17/(2·0.576) = **27.7 V**，峰值下限 = 24 + √(576 + 767) = **60.6 V** —— 而实测正是 **60 V** ✓✓。
也就是说**测量值正好落在理论下限上**：这块板的设计点就是 Ω = π（复位正好在关断期末完成，驼峰正好填满关断期 ✓ 与波形一致），此时峰值取全局最小。
（我上一轮说"60 V 低于下限、必有阻尼或钳位"是错的，原因是那个 2 倍的错误；现在结论反过来：**既不需要阻尼也不需要钳位**，与用户"没有串电阻、没有钳位"完全一致 ✓✓。）

**由此反推复位电容**（这一步是新的关键输出）：

| 反推方式 | 结果 |
|---|---|
| 按波形形状（Ω = π）：`C_res = (t_off/π)²/Lm` | **3.25 nF** |
| 按实测峰值、固定 Lm = 165 µH（环形解扫 C） | **≈ 3.2 nF** |
| 按实测峰值、固定 C_res = 1 nF（环形解扫 Lm） | ≈ 476~536 µH（但承认书 + 拆解已确认初级是 165 µH） |

**结论：板上那只复位电容的实际容量应该是 ≈3.2 nF，而不是 1 nF。** 而若真是 1 nF，模型在 24 V 下的环形解是 Ω = 405°、500 V 级——会直接炸管/饱和，与"板子稳定工作"矛盾。

### 12.7 "复位波形不是半个正弦波 / 冲顶后掉一半就开通"会造成什么（2026-10-15）

这类波形的本质是**复位角 Ω = t_off/√(Lm·C_res) 偏离 180°**（180° = 复位正好在关断期末完成 = 峰值电压与开通损耗都最小的点）。工具现在直接算三个代价：

```
Ω = t_off / √(Lm·C_res)                                    理想 180°
v_end = Vin·cosΩ − I_off·Z·sinΩ                            关断期末复位电容上的电压
开通瞬间就地烧掉的储能 = ½C·|v_end² − Vin²|（×Fs 得功率）    ← "没走完/走过头"的直接代价
复位回路电流幅值 = √(I_off² + (Vin/Z)²) → B_pk = Lm·I/(Np·Ae) ← 偏磁/饱和裕量
```

本板（Lm = 165 µH、Fs = 250 kHz、Vin_max = 36 V，磁密按 12 匝 / 52 mm² 算）扫一遍复位电容：

| C_res | Ω@18V | Ω@24V | Ω@36V | v_end@36V | 开通损耗 | I_pk | B_pk | Vds(环形解)@36V |
|---|---|---|---|---|---|---|---|---|
| 1 nF | 245° | 325° | **405°（走过头）** | −279 V | **9.6 W** | 1.07 A | **0.283 T（近饱和）** | **471 V** |
| 1.86 nF | 180° | 238° | 297° | 83 V | 1.31 W | 0.28 A | 0.074 T | 119 V |
| 2.4 nF | 158° | 210° | 261° | 19 V | 0.28 W | 0.17 A | 0.044 T | 80 V |
| **3.2 nF** | 137° | **182° ✓** | 226° | −12 V | **0.46 W** | 0.18 A | 0.047 T | **76 V** |
| 4.7 nF | 113° | 150° | 187° | −33 V | 0.11 W | 0.22 A | 0.059 T | 78 V |
| 6.8 nF | 94° | 125° | 155° | −44 V | 0.58 W | 0.29 A | 0.077 T | 82 V |
| 10 nF | 78° | 103° | 128° | −51 V | 1.69 W | 0.40 A | 0.107 T | 88 V |
| 22 nF | 52° | 69° | **86°（没走完）** | −59 V | **5.94 W** | 0.82 A | 0.217 T | 107 V |
| 47 nF | 36° | 47° | 59° | −62 V | **14.8 W** | 1.69 A | **0.448 T（饱和）** | 136 V |

**结论**：
1. **Ω ≈ 180° 是唯一的"两低点"**：峰值电压最低、开通损耗最低、复位电流最小 —— 你这块板（C ≈ 3.2 nF）正好落在这里（24 V 处 182°）。
2. **Ω > 180°（复位走过头，C 偏小）最凶**：电压与电流同时失控（1 nF 时 471 V / 1.07 A / B = 0.283 T 近饱和，开通瞬间 9.6 W 烧在开关与回路里，占输出 12.8%）。
3. **Ω < 180°（复位没走完，C 偏大）**电压升得慢些，但**开通损耗与磁密一起涨**（47 nF 时 14.8 W、B = 0.448 T 已饱和）：关断期末电容上还留着 −62 V，开通瞬间被开关与回路就地烧掉；同时磁通基线抬高（偏磁），遇到负载/输入/启动扰动就会一路爬到饱和、初级电流爆冲。
4. 工具新增：`复位角 Ω（理想 180°）`（外围校核项）、`复位回路电流磁密 B_pk ≤ Bsat 降额`（核心校核项）、以及"开通瞬间多烧 x W"的告警与步骤行。
5. 实用判据：**先把 Ω 调到 180° 附近**（`C_res ≈ (t_off(Vin_min)/π)²/Lm`），再看峰值与磁密；Ω 落在 360° 整数倍附近或很小时，模型上会"谐振累积"，实际早就炸管了。

## 13. 正激类整数匝数的正确口径：Np 守 D_max，Ns 守 ΔB（2026-10-16）

### 13.1 起因
按 240 W 单端正激（200/310/400 V → 24 V/10 A，100 kHz，D_max = 0.45，EE42/PC40，Ae = 155 mm²，ΔB 目标 0.2 T）
输入工具，得到的 Np/Ns = 30T/8T，其 **D(Vin_min) = 0.4594 > 输入的 D_max = 0.45**，而工具不报警：
当时那条校核行比的是**拓扑物理上限**（正激 0.5 / 电容复位 0.7），从没比过用户填的 D_max。

### 13.2 关键恒等式：正激的 ΔB 只由 Ns 决定
正激在 Vin_min 处由输出电压锁定占空比 `D = n·Vo/Vin_min`（n = Np/Ns），于是

```
V·t = Vin_min·D/Fs = n·Vo/Fs
ΔB  = V·t/(Np·Ae) = (Np/Ns)·Vo/(Fs·Np·Ae) = Vo·T/(Ns·Ae)      ← Np 消掉了
```

也就是说：**Np 只决定变比 n 与占空比 D，不进入磁通摆幅**；磁通摆幅由副边匝数 Ns 单独决定。
（验证：同一工况下 Np = 30 与 Np = 40 的 ΔB 完全相同，D 从 0.408 升到 0.545。）
所以整数匝只能这样取：

```
Ns：由 ΔB 目标（与 Bsat 降额取严）定 —— 多绕副边只会让磁通更安全
Np：由 D(Vin_min) ≤ D_max 定（整数匝取靠近 D_max 的一侧）—— D_max 是上限，不是目标
```

### 13.3 为什么只对正激这么改
反激的 n 同时决定 D 与磁通：把 Ns 加大能把 D 压低，但**同时把 Bpk 顶上去**（实测 EP17 一例：
改成"只守 D_max"的取整方向后 Bpk 从 0.278 T 升到 0.322 T > 降额值 0.312 T，反而判不通过）。
反激要同时动 Np 才安全，所以本轮只对 `T.kind === 'forward'` 加取整惩罚；反激/桥式保持原判据
（原有那条按拓扑上限的 `Vin_min 所需占空比 D` 校核行不变）。

### 13.4 工具改动
1. 整数匝扫描：正激时对 `dAtMin > D_max` 的那一侧加惩罚（把 D_max 当上限取整）。
2. 新增校核行（仅正激）：`Vin_min 处实际占空比 D ≤ 输入 D_max（整数匝，复位需关断时间）`。
3. 新增校核行（全拓扑，只提示不判 FAIL）：`磁通摆幅 ΔB_pp（实际）vs 目标 ΔB_pp`
   —— 目标摆幅是设计目标，硬极限仍是 Bsat 降额那条。

### 13.5 耐压档的三个口径（修正"自相矛盾"）
原来选型步骤里只给"复位窗口口径"（存在某个 C_res 能把峰值压到 0.85×耐压以下），
于是出现"建议 800 V 档，但 Vds,pk 校核连 1000 V 都判不通过"的矛盾。现在 `capReset` 里同时给三个：

| 字段 | 含义 |
|---|---|
| `vdsClassNeed` | 复位**窗口**口径：存在 C_res（≤ 关断期内复位的上限）使 Vds,pk ≤ 0.85×Vrated |
| `vdsClassStress` | **保守上界**口径：Vds,pk = Vin_max + 复位峰值 + 漏感尖峰 反推的最小标准档 |
| `vdsClassRing` | **环形（谐振稳态）解**口径：按 Vds,pk_ring 反推的最小标准档 |
| `vdsRecClass` | max(窗口, 保守) —— 与工具自己的 Vds,pk 校核兼容的最小档 |

选型卡按 `vdsClassRing` 给档（实测证明真实峰值落在环形解附近），但文字里同时列出另外两个口径：
无法实测漏感/Vds 时应向保守上界那一侧留裕量。

| **0.25mm×2×3** | 0.294 mm² | 10.1 | **1.42 W** | **41 K** | 42% | 推荐；填充率贴 Ku 上限 |
| 副边 0.25×2×3 + 原边 0.4×3×2 | — | 10.1 | 1.14 W | 33 K | 52% | 需更大窗口 |

**结论**：EPC19 的窗口（Aw = 38 mm²）已经是约束（AwReq 32.4 → 12.8 mm² 铜）。
只换磁芯不加铜会更热（MLT 变长）：EE25/13/7（Aw 54）同线径反而 2.63 W；EE30/15/7（Aw 73）3.11 W。
要真正降到 20 K 级，得"ETD29（Aw 104）+ 0.4mm 级副边"这种组合。

### 14.4 另外两个容易误判的点

1. **复位电容 3.2 nF 是对的**：250 kHz 下它让 Vin_min 处 Ω ≈ 180°（复位最优），
   环形解在 24/36 V 分别给 60.7 V / 76.1 V，与实测 57.2 V @24 V 一致（差 6%）。
   别为了"降低峰值"去减小 C_res（那会让 Ω > 180°，电压与电流一起失控，见 §12.7）。
2. **100 V 管在 36 V 输入只剩 ~10% 余量**：环形解 76 V vs 0.85×100 = 85 V。
   两种改法：C_res 提到 4.7 nF（窗口变成 4.8~7.4 nF，D 不变）或换 150 V 管。
3. **T2（输出电感）可能是更热的那一个**：38T/145 µH 若用 0.4mm×4（0.5 mm²）→ Rdc ≈ 50 mΩ、0.76~1.15 W；
   若是 0.25mm 级细线 → Rdc 可到 250 mΩ、4 W。**先测 T2 的 DCR 再决定改谁。**

### 14.5 顺带修掉的健壮性问题

校核脚本/CSV 直接驱动引擎时若漏传 `kPack` / `kuMax`，填充率会变成 `NaN`（进而误判"窗口填充率不通过"）。
引擎现在对这两个系数做兜底归一（1.25 / 0.4，与界面默认值一致），界面行为不变。

## 15. v2 与 v3 的口径差异（2026-10-16，用户问"v3 是不是更好"）

用户手上的 v3（`transformer_design_tool_v3_final14.html`）是 v2 的分支。用同一套验证脚本压 v3：
**620 通过 / 46 失败**（其中约 10 条是 v3 缺少后续新加的校核行）。两版**环形（谐振稳态）解逐位一致**，
差异集中在下面五处，逐条给判据：

### 15.1 复位电容的"硬上限"：两层判据 vs 合并成一层

```
v2：crMaxNf      = (1-D)²/(π²·Lm·Fs²)        ← Ω = π（驼峰正好填满关断期）＝ 设计最优值
    crHardMaxNf  = 4 × crMaxNf               ← 磁通刚好在关断期末复位（I_res >> Vin/Z 那一端的极限）
    crNf(自动)   = crHardMaxNf / 4 = crMaxNf
v3：crHardMaxNf  = crMaxNf                   ← 把上式的"最优值"当成硬上限
    crNf(自动)   = crHardMaxNf / 4 = crMaxNf / 4   ⇒ 复位峰值 V_res ∝ 1/√C 翻倍
```

**判据**：磁通复位条件由逐点解给出——关断期相位 Ω = t_off/√(Lm·C) 必须 ≥ 磁通过零相位
`ωt₁ = π − arctan(I_off·Z/Vin)`，而 ωt₁ ∈ (90°, 180°) 随工作点变化：

```
I_off·Z >> Vin（谐振电流相对大）→ ωt₁ → 90° ⇒ C 上限 = 4(t_off/π)²/Lm   ← v2 的 crHardMaxNf（宽松端）
I_off·Z << Vin（谐振电流相对小）→ ωt₁ → 180° ⇒ C 上限 =  (t_off/π)²/Lm   ← v3 的 crHardMaxNf（严格端）
```

两版各自只取了一端。实板（12T/23T、AL = 1146、250 kHz、C_res ≈ 3.2 nF）在 Vin_min = 18 V 处
I_off·Z/Vin ≈ 2.2 → 严格解 C 上限 ≈ **4.6 nF**：v2 的 7.43 nF 偏松、v3 的 1.86 nF 偏紧
（会把这块**能工作**的板判成"复位来不及时"）。⇒ 结论：**上限要用工作点的 ωt₁ 逐点解**，
再保留"最优点（Ω = π）"作为设计建议，而不是把两者混成一个数。

### 15.2 漏感尖峰的电流取谁

```
v2：iLkTurn = 折算到原边的负载电流 (Iout + ΔI_L/2)/n     ← 关断瞬间漏感里流的是"全部"原边电流（含负载分量）
v3：iLkTurn = iMagPk（只取励磁电流）                      ← 丢掉主项
```

实板工况（Lk = 0.3 µH、C_res = 1 nF）v2 给 ΔV = 99.7 V、v3 给 3.0 V（差 33×，能量差 ~1100×）。
正激类只有"折算到原边的那部分漏感能量"进复位电容（见 §12 的 k_p 拆分），但那部分的**电流**是负载折算电流，
不是励磁电流。⇒ v3 的开关应力会被系统性低估。

### 15.3 正激的整数匝：v3 仍会让 D 顶破输入的 D_max

240 W 例：v2 取 30T/9T（D = 0.408 ≤ 0.45），v3 取 30T/8T（D = 0.459 > 0.45）。判据同第 13 节。

### 15.4 输出电感：v3 删了 ΔI_L 输入却没清理引用

v3 改成 `buckMode` + `buckRippleK`（默认 BCM，K = 2），L_out 从 56.5 µH 变 28.6 µH；
但引擎的 IDS 列表与 `iDesignPri` 仍在引用已从界面删除的 `rippleLout` —— 悬空引用（读取会拿到 null）。

### 15.5 v3 真正的优势：CCM/BCM/DCM 显式模式选择

`fbMode`（反激）与 `buckMode`（Buck 型副边）带 DCM 专用公式：

```
DCM 反激：Lp   = Vin²·D²/(2·Pin·Fs)
DCM 副边：Lout = (Vs−Vo)²·D²/(2·Pout·Fs)
BCM    ：K = 2（谷值 = 0）
```

这部分应当**移植进 v2**（保留 v2 的物理内核），而不是反过来采用 v3 的引擎。

### 15.6 本轮顺带修的"假红"

引擎对漏传/非法的绕组输入（线径模式、股数、并联数、线径）做兜底归一：
未知模式按 `auto`、股数/并联数至少 1、线径缺失按 0.4 mm。否则 Pcu / 温升 / 填充率会静默变 `NaN`，
再被当成"校核不通过"——这是实战里最容易让人误以为"工具不准"的一类假红。

## 16. 占空比上限拆成三层：拓扑/电路 · 控制器 · 设计裕量（2026-10-16，用户要求）

### 16.1 为什么要拆

旧版只有一个 `dLimit`，把 0.60（反激/ACF）、0.50（正激/LLC）、0.48（推挽/半桥/全桥）说成"物理上限"，
并且用它去钳位用户输入。后果是：**D = 0.627 的反激会被判"物理上无法工作"**——但 0.60 只是工程默认值，
真正能不能工作取决于控制器、器件耐压与复位条件。现在拆成三口径，各自单独校核：

```
D_allowed = min(D_topology, D_controller, D_design)        ← 作为"设计目标占空比"去算变比/匝数
校核：D ≤ D_topology （硬性，能推就推，推不出就说明"无本质上限"）
      D ≤ D_controller（硬性）
      D vs D_design   （**只提示确认裕量，不判失败**）
```

### 16.2 各拓扑的默认值与"上限怎么来的"

| 拓扑 | D_topology（硬） | D_controller（默认，可改） | D_design（默认，可改） | 真正约束 |
|---|---|---|---|---|
| Flyback | 无固定值（填了开关管耐压才按 V_or 反推） | 0.95 | **0.60** | V_or、开关管耐压、复位时间 |
| ACF | V_clamp = Vin·D/(1−D) 受耐压限制 → 由 0.85·Vds 反推 | 0.95 | **0.60** | 钳位电容电压、软开关（ZVS） |
| Forward（绕组复位） | **D ≤ Nr/(Nr+Np)**（1:1 时 0.50） | 0.95 | 0.45 | 复位绕组匝比 |
| Forward（电容复位） | **按复位电路逐点算**（见 16.3） | 0.95 | 0.60 | 磁通能否在关断期内回零 |
| Push-Pull / 半桥 / 全桥 | 0.50（**单管**占空比，另半周期给另一只管子） | **0.5 − t_dead·Fs**（200 ns/100 kHz → 0.48） | 0.45 | 两路驱动重叠/死区、磁通平衡 |
| LLC | 0.50（互补驱动标称） | 0.50 | 0.50 | 频率范围、增益曲线、软开关 |

### 16.3 电容复位正激的上限是"算出来的"

判据：磁通必须在关断期内回零。磁通过零相位 ωt₁ = π − arctan(I_off·Z/Vin_min)，
关断期相位 Ω = t_off/√(Lm·C_res)，条件 **Ω ≥ ωt₁**（I_off 由环形稳态闭合方程给出，与 §12 同一套模型）。
所以 `D_topology` 随 C_res / Lm / Fs 变化，不能用一个固定数字代替：

```
240 W 例（Lm = 4.16 mH, Fs = 100 kHz, Vin_min = 200 V）：
   C_res = 0.55 nF → D_topo ≈ 0.73
   C_res = 0.85 nF → D_topo ≈ 0.65
   C_res = 3.2 nF  → 扫不到可行点（任何 D 都来不及复位）→ 硬性不通过并给出改法
```

注意方向：**C_res 越大复位越慢、上限越低**（但复位峰值越低），两者要对折中——Ω ≈ 180°（复位正好填满关断期）
是峰值与开通损耗都最低的工作点。

### 16.4 ACF 新增的钳位与软开关校核

```
钳位电容稳态电压 V_clamp = Vin·D/(1−D) → 主管承压 = Vin + V_clamp（漏感能量进钳位电容，不叠尖峰）
软开关（无载最差）：励磁半幅 I_Lm,pk = Vin·D/(2·Lm·Fs) ≥ 2·Coss·V_clamp/t_dead
新增步骤行给出 V_clamp 范围、主管承压、钳位电容/开关管建议耐压；新增两条校核：主开关耐压、无载 ZVS
```

## 18. 开关管 Vds 与副边整流耐压：按拓扑分别算（2026-10-19，用户对账表）

用户指出 V3（以及 V2）的选型卡对"非电容复位拓扑"一律用 `1.4·Vin_max`，副边整流管一律用
`0.6·Vin_max/n + Vo`，并给出了一张"代码 vs 正确值"的对账表。**核对结论：方向全部正确，
有两处要修正数值/补漏**：

### 18.1 旧代码的实际口径

```
开关管：var vdsWorst = cr ? 环形解 : 1.4·Vin_max           ← cr 只有"正激+电容复位"才非空
整流管：var vResPkMax = cr ? 环形复位峰值 : 0.6·Vin_max     ← 其余拓扑一律 0.6·Vin_max
        vSecOff = vResPkMax/n + Vo
```

### 18.2 逐拓扑判定（用户表 + 修正）

| 拓扑 | 旧代码 | 正确 | 判定 |

### 18.3 新模型（v3）

```
开关管 Vds,pk：
  反激            (Vin_max + n·Vo) × 1.15          尖峰按 15% 余量（有实测波形时用实测值覆盖）
  正激-电容复位    环形解（含漏感）                  不变
  正激-复位绕组    Vin_max·(1 + Np/Nr) × 1.15

  LLC（半桥）       Vin_max × 1.05（ZVS，尖峰小）
  vdsMeasPk > 0 时取 max(模型, 实测)

副边整流管 Vr（关断期）：
  正激-电容复位    环形复位峰值/n + Vo
  正激-复位绕组    Vin_max·(Np/Nr)/n + Vo
  推挽/全桥/半桥   (vPri_max × secTapK)/n + Vo
                    vPri_max = Vin_max（推挽/全桥）或 Vin_max/2（半桥、LLC）

```

### 20.1 单端正激：ON Semiconductor NCP1216AFORWGEVB（EVBUM2133-D）

```

实际规格：Vin 36~72 V（文档 eq.4 保守按 Vin_max = 80 V 算）、Vout 12 V / 3 A、f = 100 kHz、
          EFD25（Ae = 58 mm²）、D_max = 0.5、复位绕组 1:1、ΔB_max = 0.2 T、η > 85%
文档结论：Np = 35、Ns = 25
          （eq.4：Np = Vin_max·D_max/(ΔB·f·Ae)；eq.5：Ns = Np·(Vout+Vf)/(Vin_min·D_max)）
```

| 量 | 厂商参考 | 工具（同规格） | 差 |
|---|---|---|---|
| 匝比 n | 1.400 | **1.333** | −4.8%（整数匝 + Vf 取值） |

**结论**：匝**比**对得上（5% 内）；匝**数**差 2.2 倍是**基准不同** —— 厂商用"最恶劣 V·t = Vin_max·D_max"
定 Np，本工具用稳态 V·t = n·Vo/Fs（= Vin_min·D_max）。两者稳态都安全，但启动/负载阶跃时若控制器把占空比
打满，只有厂商基准覆盖得住。→ **新增校核行** `瞬态磁通裕量：Bpk(@Vin_max·D_max) ≤ Bsat·降额`，
超限时直接给"厂商基准需要 Np ≥ X 匝"或"把 Vin_max 处占空比压到 Y 以内"。
