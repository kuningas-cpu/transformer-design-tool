热 / Thermal

Rth 是谁的？是这颗变压器本身的热阻——从绕组/磁芯热点到环境（取绕组温升来校核），单位 K/W。 工具用它算 ΔT = (P_core + P_cu)·Rth，再把 ΔT 加回环境温度作为绕组温度、 用该温度重算铜的电阻率 ρ(T) 与趋肤深度（所以温升会影响铜损，是个迭代收敛过程）。 它不是器件/磁芯的数据手册参数：同一颗磁芯，装法（是否坐在大铜箔上、是否点胶/灌封、有无风）、骨架、散热面积都影响它。 取值办法：① 最好实测反推——让样机在已知损耗 P 下工作，测热点温度 Rth = (T_热点 − T_环境)/P； ② 估算法 Rth ≈ 1/(h·A_表面)，自然对流+辐射的等效 h ≈ 10~15 W/(m²·K)， EPC19 级表面约 2×10⁻³ m² → 30 K/W 上下；③ 经验值：小 EP/EPC 变压器自由空气 20~40 K/W，有风或贴大铜箔 10~20，密闭小腔 >40。 ★ 你这块默认 28 K/W：1 号变压器总损耗约 0.44 W → ΔT ≈ 12 K，这条校核很宽松；2 号输出电感借用同一个 Rth（同为 EPC19 骨架、同样装法时是合理近似）。

裕量与构造系数速查 / Margin & construction coefficients

参数是什么（物理含义）影响哪个结果怎么取值（★=你这块 19V/75W 板推荐）
Bsat 降额系数 铁氧体的 Bsat 随温度下降（PC40：25°C 约 0.51 T → 100°C 约 0.39 T），再留出峰值电流公差、最高输入电压、启动/过载瞬时过冲的余量后，用"Bsat@100°C × 该系数"作为允许峰值。 允许峰值 `BsatAllow`；磁通峰值 `Bpk ≤ BsatAllow` 是**硬性校核**；也间接决定最小匝数。 0.7~0.85，默认 0.8。
★ 1 号变压器 Bpk 0.082 T vs 0.312 T（3.8 倍裕量），这项无所谓；
★ **2 号输出电感才是关键**（Bpk 0.307 vs 0.312，正好压线）→ 要么留 0.75，要么让供应商补测带载电感来定。
开关管耐压降额 0.85 校核用的是"峰值电压 ≤ 0.85×耐压"，其中 Vds,pk = Vin_max + V_res,pk + ΔV_Lk：关断瞬间开关管先承受输入母线电压 Vin_max，再加上复位电容被励磁电流充到的峰值 V_res,pk = I_m,pk·√(Lm/C_res) = n·Vo/(Fs·√(Lm·C_res))，再加漏感能量灌进复位电容的额外抬升 ΔV_Lk = I_pk,pri·√(Lk/C_res)。
0.85 不是器件参数，是"留 15% 余量"的经验约定：① 耐压 BVdss 标称在 25°C，高温下雪崩击穿电压会下降；② 最高输入电压本身有公差（常按 +5~10% 算）；③ 上式 ΔV_Lk 是把漏感能量全部算进 C_res 的上界——实际有阻尼与绕组损耗会低一些，但还会有振铃/尖峰；④ 电感、驱动与器件有批量一致性偏差。业界常用 80%~90%，高温/高压场合取 0.8。		 校核清单里"开关管电压应力 Vds,pk ≤ 0.85×耐压"这一行；也用来定"该选多大耐压的 MOS"：把 Vds,pk ÷ 0.85 向上取标准档（250 / 400 / 500 V…）。 工具固定用 0.85（另在 0.9×限值 处给"接近上限"提示），要更保守就自己按 0.8 再核一遍。
★ 你这块（正激 + 电容复位、Vin_max = 36 V、AL = 1146 nH/N²、12 匝 → Lm = 165 µH）：自动取到的 C_res 上限 2.9 nF 时 V_res,pk ≈ 73.5 V；主导项是漏感——Lk = 0.8 µH → ΔV_Lk ≈ 135 V → Vds,pk ≈ 245 V（超过 250 V 档的 212.5 V 限值）；若 Lk 只有 0.2 µH → ΔV ≈ 68 V → Vds,pk ≈ 177 V 通过。→ 请把实测漏感 Lk 与板上实际的 C_res 填进来，这两个数决定这条结论。
高频电阻系数 F_R 趋肤效应 + 邻近效应让交流电阻高于直流电阻。100 kHz 下铜的趋肤深度 δ≈0.21 mm（25°C）/0.24 mm（100°C），单股线径超过约 1~1.5δ 时电流挤向表面，Rac/Rdc 上升。 铜损 `P_cu = Σ I_rms²·R_dc·F_R` → 温升。只影响损耗/温升，不影响匝数与磁通。 按线径/δ 估：≤0.5δ →1.0；≈δ →1.05~1.15；≈1.5δ →1.2~1.35；≈2δ →1.5~1.8；≥3δ →≥2；利兹线 1.05~1.15。
★ 你两块都是 0.25/0.4 mm 单层密绕：0.25 mm≈1.0δ → **1.1~1.2**；0.4 mm≈1.7δ → **1.3~1.4**（工具"股线直径 vs 趋肤深度"那行会提示）。
目标磁通摆幅 ΔB_pp (T) 你**希望**一个开关周期内磁通密度的峰峰摆幅，是**设计目标**（不是硬限值）。磁芯损耗随它约 2.4~2.8 次方上升，而匝数与铜损随它反比下降，所以它是"铁损 ↔ 铜损/窗口"的取舍旋钮。 决定**最小匝数** `Np ≥ V·t/(Ae·ΔB_pp)`，并参与磁芯损耗估算（工具按 ΔB_pp/2 作等效交流幅值）。故意填小 → 匝数多、铜损大；填大 → 铁损大、易饱和。 100 kHz 铁氧体常用 0.15~0.25 T；200~500 kHz 取 0.1~0.15 T。
★ 你板子实测摆幅只有 0.082 T（因为匝数是 12 匝、由供应商按饱和余量定的）→ 保持 0.2 即可，工具只会给一条"给定 Np 已大于磁通下限"的提示，不是问题。
平均匝长 MLT (mm) 绕一圈的平均周长（＝磁芯柱周长 + 两倍绕组搭建厚度），是"导线用了多长"的几何量。 直流电阻 `R_dc = ρ·MLT·N/A_cu` → 铜损、DCR 校核、温升。与 MLT 成正比。 按骨架尺寸估，或**由承认书 DCR 反推**（推荐）。
已验证量级：1 号原边（12 匝、内层）≈**38 mm**；2 号 38 匝（中层）≈**32 mm**；2 号 25 匝辅助（最外层）≈**44 mm** → 绕层不同差 ±20%，可用我新加的"MLT 最坏偏差"做保守校核。
绕线填充系数 k_pack 把**裸铜面积**放大到实际占位的系数：圆线之间必然有三角空隙（面积利用率仅 π/4≈0.785），再加漆膜厚度 → 排绕约 1.1，乱绕 1.2~1.4，手绕很乱可到 1.5；利兹/矩形线更小。 窗口填充率 `fill = Σ裸铜·k_pack/有效窗口`，与 Ku 一起决定"装不装得下"。 排绕单层 1.1~1.2；乱绕 1.25~1.4。
★ 你两家承认书都写"均匀密绕 1 层" → **1.15~1.25** 合适（工具默认 1.25 稍保守）。
窗口利用率上限 Ku 骨架窗口里**允许绕组占用的比例上限**（含铜、漆膜、层间胶带、挡墙胶带）。安规间距越大、层数越多，能用的比例就越低。 校核 `fill ≤ Ku`，并给出"满足 Ku 所需窗口面积 Aw"，便于与骨架实际窗口对照。 0.3~0.4（圆线+胶带+挡墙）；单层简单结构可到 0.45~0.5；矩形线 0.5~0.6。
★ 你这块若要 1500 Vac 加强绝缘：**取 0.35**，并在"窗口与绝缘"里填骨架窗口宽高与挡墙每侧宽度，工具会按 `(宽−2×挡墙)×高` 算有效窗口（填充率才真实）。
热阻 Rth (K/W) 这颗变压器自己的热阻：从绕组/磁芯热点到环境（工具按绕组温升校核），ΔT = (P_core + P_cu)·Rth。 它不是磁芯或器件的数据手册参数，而是"磁芯 + 骨架 + 装法 + 散热面积"的系统量：同一颗磁芯，坐在大铜箔上/点胶灌封/有风 与 悬空无风 能差 2~3 倍。 工具把磁芯损耗与铜损当成一个热源（集中热阻模型），并用算出的热点温度反算铜的电阻率 ρ(T) 与趋肤深度——所以温升与铜损是耦合的（工具内部迭代收敛）。 温升 ΔT、所需热阻 Rth_max = ΔT_目标/P_总、绕组工作温度（进而 ρ(T)→DCR→铜损）；也决定"要不要降 J 或换更大磁芯"。 输出电感（2 号）也借用同一个 Rth，它自己的损耗与温升独立计算、不计入变压器温升。 ① 最好实测反推：样机工作到已知损耗 P，测热点温度 → Rth = (T_热点 − T_环境)/P； ② 估算 Rth ≈ 1/(h·A_表面)，自然对流+辐射等效 h ≈ 10~15 W/(m²·K)，EPC19 级表面约 2×10⁻³ m² → 约 30 K/W； ③ 经验值（自由空气、无风）：EPC19/EP20 级 25~35 K/W；更小的 EE16/EP13 级 40~60；点胶/灌封或贴大铜箔 15~25；有风再降一档；密闭无风小腔 >40。
★ 你这块默认 28 K/W：1 号变压器损耗约 0.44 W → ΔT ≈ 12 K，很宽松；2 号输出电感同为 EPC19 骨架、同样装法，借用同一 Rth 是合理近似（若两者装法差别大，请分别核对）。
它们如何串起来（工具里的因果链）：
ΔB_pp 目标 + Bsat·降额 → 定**最小匝数** → 匝数 + 线径/股数 → 定**铜面积** → k_pack + Ku + 有效窗口 → 判断**装不装得下** → MLT + 铜面积 → 定**DCR/铜损** → F_R 放大铜损 + 磁芯损耗 → 定**温升**（ΔT = 总损耗 × 热阻 Rth；温升回头又抬高 ρ(T) → 铜损，故是迭代收敛的）。
也就是说：ΔB_pp 与 Bsat 降额决定磁路，k_pack/Ku/MLT 决定"能不能绕进去、有多重"，F_R 只决定"高频下有多热"。前两组填错会**改变设计结论**，F_R 填错只影响温升的乐观/保守程度。
符号与约定
D：原边施加电压的占空比。反激=开关导通占空比；正激=单管导通占空比（1:1 复位绕组时 D≤0.5）；推挽/半桥/全桥=每个开关（桥臂）的导通占空比，D<0.5，一周期内正负各一次。
Np：推挽指两个半绕组的总匝数（每个半绕组 Np/2），其余拓扑就是原边匝数。
ΔB_pp：一个开关周期内磁通密度峰峰摆幅；Bpk：磁通密度峰值。单极性拓扑（反激/正激）Bpk=ΔB_pp；双极性拓扑（推挽/半桥/全桥）Bpk=ΔB_pp/2。
V·t：伏秒积 = 施加电压×导通时间，ΔB = V·t/(Np·Ae)，这是匝数与磁通的唯一依据（不含 4.44 正弦系数）。
磁芯损耗按 ΔB_pp/2 作为等效交流幅值套用正弦拟合曲线；Ae/Aw/le/MLT/µi/Bsat/Pcv/α/β 全部可编辑，预设值为典型值。
LLC：D 固定 0.5（半桥驱动），原边方波幅值 = Vin/2，因此 ΔB 随 Vin 变化，需要取 Vin_max 校核；谐振腔（Lr/Cr/Lm/Q）不在本工具范围。
推挽：Np 为总匝数，但一次侧电流按每个半绕组单独计算（半绕组电流 = 2·Iout/n），窗口与铜损按"半绕组 ×2"累计。
