## 怎么用（三步）

1. 打开 `transformer_design_tool_v2.html`。
2. 选拓扑，填 Vin 范围 / Vout / Iout / Fs；磁芯从预设里选，然后**按数据手册覆盖 Ae / le / Aw / MLT**。
3. 看右侧「计算结果 + 校核清单 + 结论」；下方是输入电压扫描、设计步骤（可手工复核）、磁芯对比、拓扑公式。
   - 评审供应商承认书时：勾开「校核模式」，填供应商给出的 Np / Ns、实测 AL、线径与 DCR 上限。

## 可信边界（重要）

- **已验证**：7 个拓扑（反激 / ACF / 正激 / 推挽 / 半桥 / 全桥 / LLC）的公式、量纲、内部一致性与物理不变量；
  验证方式是独立路径互相对照——手算链、开关波形数值积分、教科书常数、能量守恒与安匝平衡，另有 7×400 例随机工况模糊测试。
- **未验证**：**没有任何样机实测对照**（不存在这类数据）；磁芯几何与材质参数是典型预设值，必须用数据手册覆盖；
  漏感与绕组排布、EMI、绝缘/安规、启动与短路等瞬态未建模。
- 结论只是"快速设计 / 校核"，正式设计以数据手册 + 样机实测为准。**不要用工具的"通过"替代样机验证。**

## 能算 / 不能算

**能算**：变比与整数匝数（伏秒平衡 ΔB = V·t/(Np·Ae)）、所需占空比、峰值与有效值电流、磁通摆幅与峰值、
饱和裕量、原边电感与所需 AL / 气隙、复位绕组匝比、窗口填充率、绕组电流密度、铜损（含高频系数）、
磁芯损耗、温升与所需热阻、直流电阻 DCR、趋肤深度。

**不能算**：LLC 谐振腔（Lr / Cr / Lm / Q / 增益曲线 / 软开关范围）、漏感与绕组排布、EMI、
绝缘与安规距离、控制器与保护逻辑、输出电感与电容的选型。

## 后续可做 —— 完成情况（2026-10-15 更新）

1. **Excel / CSV 版本：已完成（附验证边界）**
   `make_excel_from_v2_engine.py` 由同一套公式生成 `transformer_design_tool_v2.xlsx`（输入 / 计算 / 校核 / 磁芯库 / 材质 / 说明 六张表 + 活体自检区）。
   用 `formulas` 公式求值器与引擎逐格比对：**反激分支 19/19 项一致**；正激/推挽/半桥/全桥/LLC 分支结构相同但仍有 3~4 处偏差未定位（励磁电感单位、桥式原边有效值电流）。
   → **在非反激拓扑下请以网页版为准**，Excel 版在非反激拓扑下视为需人工复核的草稿（该提示已写入工作簿"说明"表）。
   CSV：网页版"导出 CSV"按钮输出的即为 v2 引擎结果（含校核清单与电压扫描）。
2. **磁芯库数据：部分完成**
   每条磁芯增加"来源"标注（preset 预设 / measured 实测 / user 用户），EPC19 已填入天胜 TST1724 承认书的实测 AL=1146 nH/N² 与由 DCR 反推的 MLT≈38 mm；
   其余仍为族量级预设值。网页版新增"磁芯库维护"卡片：可粘贴 CSV（model,family,Ae,le,Aw,MLT,AL_measured,src,note）替换整库并保存在本机浏览器。
   → **其余磁芯的精确 Ae/le/Aw/MLT 仍需按数据手册填入**（这是数据录入工作，不由工具臆造）。
3. **输出级：已完成** 输出电感（含 DC 偏置饱和、AL/气隙、铜损、温升）、输出电容（纹波预算分解 ESR 与容性分量、纹波电流、ESR 上限、耐压建议）、同步整流 vs 二极管（损耗对比与临界电流）。
4. **LLC 谐振腔：已完成（一阶谐波近似 FHA）** 由增益需求反解 Q_max（二分）、给出 Lr/Cr/Lm、增益曲线表、调频范围、谐振电容应力、ZVS 判据（I_Lm,pk ≥ 2·Coss·Vin/t_dead），并把"所需 Lm"与磁芯 AL·Np² 挂钩给出所需气隙。
   边界：FHA 忽略高次谐波与寄生参数，最终以仿真/实测为准。
5. **回归测试：已完成** 新增 EPC19 承认书工况与 5 个基线场景（反激/正激/半桥/推挽/LLC）的钉死数值比对，以及输出级与 LLC 谐振腔的公式验证。
   验证脚本从 309 项增加到 **379 项**，全部通过。
