## 怎么用（三步）

1. 打开 `transformer_design_tool_v2.html`。
2. 选拓扑，填 Vin 范围 / Vout / Iout / Fs；磁芯从预设里选，然后**按数据手册覆盖 Ae / le / Aw / MLT**。
3. 看右侧「计算结果 + 校核清单 + 结论」；下方是输入电压扫描、设计步骤（可手工复核）、磁芯对比、拓扑公式。
   - 评审供应商承认书时：勾开「校核模式」，填供应商给出的 Np / Ns、实测 AL、线径与 DCR 上限。

## 可信边界（重要）

- **已验证**：7 个拓扑（反激 / ACF / 正激 / 推挽 / 半桥 / 全桥 / LLC）的公式、量纲、内部一致性与物理不变量；
  验证方式是独立路径互相对照——手算链、开关波形数值积分、教科书常数、能量守恒与安匝平衡，另有 7×400 例随机工况模糊测试。
- **未验证**：**没有任何样机实测对照**（不存在这类数据）；磁芯几何与材质参数是典型预设值，必须用数据手册覆盖；
  漏感与绕组排布、EMI、绝缘/安规、启动与短路等瞬态未建模。
- 结论只是"快速设计 / 校核"，正式设计以数据手册 + 样机实测为准。**不要用工具的"通过"替代样机验证。**

## 能算 / 不能算

**能算**：变比与整数匝数（伏秒平衡 ΔB = V·t/(Np·Ae)）、所需占空比、峰值与有效值电流、磁通摆幅与峰值、
饱和裕量、原边电感与所需 AL / 气隙、复位绕组匝比、窗口填充率、绕组电流密度、铜损（含高频系数）、
磁芯损耗、温升与所需热阻、直流电阻 DCR、趋肤深度。

**不能算**：LLC 谐振腔（Lr / Cr / Lm / Q / 增益曲线 / 软开关范围）、漏感与绕组排布、EMI、
绝缘与安规距离、控制器与保护逻辑、输出电感与电容的选型。

### 第三轮：AL 与"不开气隙"的坑（2026-10-15）

**现象**：磁芯"不开气隙"，AL 填 0 → 算出的电感与匝数比承认书差数倍。

**原因（两层）**：
1. **"不开气隙"是工艺说法，不等于零有效气隙**。对拼面平面度/研磨残留会留下几十微米的有效气隙，
   而闭合磁路里这点气隙的磁阻与 `le/µi` 同量级 → 实测 AL 常只有理想无气隙值 `µ0·µi·Ae/le` 的 1/3~1/2。
   以 EPC19/PC44/Ae=52/le=32 为例：理想值 ≈ 4700~4900 nH/N²，而天胜承认书实测 **1146 nH/N²**（差 4.1~4.3 倍）
   → 反推等效有效气隙仅 **0.043 mm**。此时电感 `L = AL·N²` 与反激的 `Np ∝ √(Lp/AL)` 都会偏大数倍。
2. **拓扑与模式**：工具默认反激且会自行解算匝数；本板是正激、12/23 固定匝数，必须选"正激 + 校核模式"
   （或直接用"载入我的板子(19V/75W)"预设），否则变比方程本身就是另一套。

**工具侧改动**：
- 新增"磁芯库实测 AL"通道：**AL 输入为 0 时优先用磁芯库里的实测值**（选中 EPC19 预设会自动带入 1146），
  显式填写的 AL 仍然优先；
- 新增"AL 取值与等效有效气隙"设计步骤行：同时给出理想值、实际用的值、由 AL 反推的**等效有效气隙**；
- 回落到理想无气隙值时会**明确告警**并给出"实测常只有理想 1/3~1/2"的量级提示，避免再踩；
- 回归测试新增第 26 组：库内实测 AL → Lm = 165.0 µH（与承认书一致）、理想值路径 4.1~4.3 倍差、等效气隙 0.043 mm。

- **Excel 版非反激分支**：公式结构与反激一致且经人工复核，但所用的公式求值器（Python `formulas`）在这几支上给出错误结果（引擎给出 1.65 A、求值器给 37 A），**无法在本机完成逐格验证** → 工作簿说明页已标注"非反激拓扑以网页版为准"。用真实 Excel 打开后看"校核"表末尾的活体自检行即可当场确认（偏差应≈0）。
- 磁芯库精确几何/材质数据（需数据手册输入；工具已提供导入通道与"实测 AL 与几何推算对照"自检行来暴露错误数据）。
- MLT 按绕层分别建模（现为单值 + 可选最坏偏差；实测分布为内层≈32 mm、最外层≈44 mm）。

### 第四轮：输入面板按「输入类型 / 拓扑 / 次级整流器件」动态显示（2026-10-15）

**为什么改**：选「直流输入」时，交流前端那一大片参数（Vac / 工频 / C_bus / ESR / 源阻 / 桥压降 / 保持时间 / PFC 母线）
仍然显示，既是干扰也容易误填；反过来选「交流」时 Vin_min / Vin_max 已被母线仿真覆盖，显示出来会让人以为要自己填。

**做法**：每个条件相关的输入项在 HTML 上带一条 `data-show` 规则（竖线 = 或，& = 且，`键:值1,值2`），
`render()` 每次先执行 `updateVisibility()`，按当前 输入类型 / 拓扑 / 次级整流器件 决定显示哪些项。
语法与全部规则见 `transformer_design_tool_v2_notes.md`。**被隐藏的输入仍保留数值**（切回去即恢复），不参与该工况计算的项本来也不会被引擎使用。

### 第四轮补充：输入参数前置 + 「反激没有续流管」（2026-10-15）

**① 输入参数移到最前**：面板顺序改为 **输入类型与输入电压 → 规格 → 拓扑工作点 → 磁芯 → 材质 → 绕组 → 输出级 → LLC → 校核模式 → 窗口与绝缘 → 热**。
原来 Vin_min / Vin_max 混在"规格"里、交流前端单列一节，现在输入类参数（输入类型、Vin_min / Vin_max 或 Vac / 工频 / C_bus / …）合成第一块，先定输入再看输出与拓扑。

**② 反激确实不需要续流管——工具的措辞原来把它当成"整流+续流"两只管子**。修正如下（数值模型本来就是对的，改的是口径表达与选项）：

| 拓扑 | 续流管 | 现在的措辞 |
|---|---|---|
| 反激 / ACF | **没有**（副边只有一只整流管，关断期导通给输出电容充电） | 二极管（副边单管，无续流管）/ 同步整流（副边单管）；sr2 选项**收起**并归到单管 |
| 正激 / 推挽 / 半桥 / 全桥 | 有（Buck 型副边带输出电感） | 二极管（整流管 + 续流管）/ 同步整流（只换整流管 + 续流二极管）/ 同步整流（两管都换） |
| LLC | **没有**（副边整流管在半个周期内交替导通） | 二极管（副边整流管，交替导通，无续流管）/ 同步整流（副边整流管换成 MOS）；sr2 同样收起 |

配套改动：次级整流器件下方新增随拓扑变化的提示行；设计步骤与结果行的措辞随拓扑切换；
若直接调用引擎传 `sr2 + 反激/LLC`，会给出提示并按单管（实际副边电流波形）计算，不再按"两只管子"估算。

### 第七轮：说清"热阻 Rth (K/W) 是谁的"（2026-10-15）

**问题**：热/热力学小节里只有"热阻 Rth (K/W)"一个标签，既没说清是变压器还是整机/器件的，也没说清它不是数据手册参数。

**回答（也是现在页面上的文字）**：Rth 是**这颗变压器自己的热阻**——从绕组/磁芯**热点到环境**，用来校核绕组温升：
`ΔT = (P_core + P_cu)·Rth`，`T_热点 = T_环境 + ΔT`，`Rth_max = ΔT_目标/P_总`。
因为算出的热点温度会回头影响铜的 ρ(T)（进而铜损），`ΔT` 对 Rth 是**超线性**的（本板 28 → 56 K/W 时 ΔT 从 58.6 K 涨到 148.2 K，2.53 倍）。
它**不是磁芯/器件的数据手册参数**，而是"磁芯 + 骨架 + 装法 + 散热面积"的系统量：取值优先级 ① 实测反推 `Rth=(T_热点−T_环境)/P_损耗`、
② 估算 `Rth≈1/(h·A_表面)`（自然对流+辐射 h≈10~15 W/(m²·K)，EPC19 级表面约 2×10⁻³ m² → 约 30 K/W）、
③ 经验值（自由空气无风）：EPC19/EP20 级 25~35、EE16/EP13 级 40~60、点胶灌封或贴大铜箔 15~25、密闭无风小腔 >40。
另外 **2 号输出电感借用同一个 Rth**（它自己的损耗/温升独立计算、不计入变压器温升；两块同为 EPC19 骨架时这个借用是合理近似）。

**验证**：新增第 31 组 13 项（ΔT 恒等式、T_热点 恒等式、Rth_max 定义、Rth 翻倍时 ΔT 超线性、环境温度耦合、
