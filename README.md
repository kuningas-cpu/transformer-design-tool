## 怎么用（三步）

1. 打开 `transformer_design_tool_v2.html`。
2. 选拓扑，填 Vin 范围 / Vout / Iout / Fs；磁芯从预设里选，然后**按数据手册覆盖 Ae / le / Aw / MLT**。
3. 看右侧「计算结果 + 校核清单 + 结论」；下方是输入电压扫描、设计步骤（可手工复核）、磁芯对比、拓扑公式。
   - 评审供应商承认书时：勾开「校核模式」，填供应商给出的 Np / Ns、实测 AL、线径与 DCR 上限。

## 可信边界（重要）

- **已验证**：7 个拓扑（反激 / ACF / 正激 / 推挽 / 半桥 / 全桥 / LLC）的公式、量纲、内部一致性与物理不变量；
  验证方式是独立路径互相对照——手算链、开关波形数值积分、教科书常数、能量守恒与安匝平衡，另有 7×400 例随机工况模糊测试。
- **未验证**：**没有任何样机实测对照**（不存在这类数据）；磁芯几何与材质参数是典型预设值，必须用数据手册覆盖；
  漏感与绕组排布、EMI、绝缘/安规、启动与短路等瞬态未建模。
- 结论只是"快速设计 / 校核"，正式设计以数据手册 + 样机实测为准。**不要用工具的"通过"替代样机验证。**

## 能算 / 不能算

**能算**：变比与整数匝数（伏秒平衡 ΔB = V·t/(Np·Ae)）、所需占空比、峰值与有效值电流、磁通摆幅与峰值、
饱和裕量、原边电感与所需 AL / 气隙、复位绕组匝比、窗口填充率、绕组电流密度、铜损（含高频系数）、
磁芯损耗、温升与所需热阻、直流电阻 DCR、趋肤深度。

**不能算**：LLC 谐振腔（Lr / Cr / Lm / Q / 增益曲线 / 软开关范围）、漏感与绕组排布、EMI、
绝缘与安规距离、控制器与保护逻辑、输出电感与电容的选型。

### 第二轮优化（2026-10-15，验证 405 → **448 项**）

按"逐项检查 → 修 → 加测试"的流程完成了下列项目：

| 项 | 处理 |
|---|---|
| **① 电容复位用错占空比** | C 上限改用 Vin_min 处**实际工作占空比**；补闭式 `V_res,pk = π·n·Vo/(1-D)`（与 Lm、Fs 无关）并在步骤里做互校 |
| **② 复位电压缺漏感项** | 新增"漏感 Lk"输入：`ΔV = Ipk·√(Lk/C)` 计入 Vds,pk，输出"漏感能量/励磁能量"比；**未填漏感时明确告警**"Vds 被低估" |
| **③ 反激 DCM** | 实现真 DCM：占空比由功率决定 `D=√(2·Pin·Lp·Fs)/Vin`、复位时间 `tr=Lp·Ipk/Vr` 需满足 `D·T+tr≤T`、峰值/RMS 按三角波；新增 3 条自检（能量、复位时间、副边电荷平衡） |
| **④ 输出电感/辅助绕组建模** | 输出电感新增自己的线径/股数/并联输入（对应 2 号"38 匝×4 并联"）；辅助绕组铜面积计入电感窗口填充；补电感窗口填充率校核 |
| **⑤ MLT 误差** | 新增"MLT 最坏偏差 %"输入，DCR 校核可按最坏情况（默认 0，不叠加；填 20 则按 +20% 校核） |
| **⑥ ACDC 前端** | 新增交流输入模式：桥式整流 + 母线电容**数值仿真**（恒功率负载、含源阻/ESR）→ 母线谷值/纹波/电容纹波电流/导通角，并**自动覆盖 Vin_min/Vin_max**；保持时间按 `V2=√(V1²−2Pt/C)` 校核并给出所需 C_bus；PFC 模式按恒定母线（默认 390 V）设计 |
| **⑦ 绝缘/窗口** | 新增骨架窗口宽×高输入与"挡墙胶带每侧宽度"，填充率按有效窗口 `(宽−2·挡墙)×高` 计算；缺窗口尺寸时明确告警 |
| **P2-1 供应商 A/B 对比** | 工具内新增"方案对比"：一行一个供应商（名称,Np,Ns,AL,电感匝数,实测电感,辅助匝数,线径/股数/并联…），逐项并排出结论、磁通、填充、DCR（单绕组）、温升、未通过项 |
| **P2-2 方案保存/预设** | 设计输入可命名保存到本机浏览器并读取；新增一键"载入我的板子(19V/75W)"（1号 12T/23T + 电容复位；2号 38T/145 µH + 25T 辅助，含漏感 0.8 µH 起始值） |
| **P2-3 设计报告** | 新增"生成设计报告（可打印）"：输入/结果/校核清单/结论/提示，一键打印或存 PDF，可直接发供应商 |
| **P2-4/p5 LLC 收尾** | 新增"高线轻载可降增益"校核（`M_min ≥ k/(k+1)×1.02`，否则需 burst/skip）、轻载所需最高频率提示、谐振电容耐压校核、`Lr/Lm=1/k` 与漏感可实现性提示，并加**增益曲线 SVG 图**（含 M_max/M_min 需求线） |
